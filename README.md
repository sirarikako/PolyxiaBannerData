# CastoriceBannerData

Public banner metadata and JSON schemas for Genshin Impact and Honkai: Star Rail.

This repository is a published data mirror maintained from the private `CastoriceWishBannerData` repository. Do not edit the synchronized folders here; updates will overwrite their contents.

- `public/`: released JSON data for client applications, versioned under `public/v1/`.
- `schemas/`: versioned JSON Schema definitions for the published data.

The two directories are synchronized automatically by GitHub Actions after validation. Other source repository folders are not published.
