# 公告识别状态一览

打开 [BANNER_STATUS.md](./BANNER_STATUS.md)，即可按版本、期数查看现有公告解析、预告、角色祈愿/跃迁、武器/光锥、V1 候选及正式数据，最新版本排在前面。

- **数据来源**：完全读取 **PolyxiaBannerData 公开运营仓库** 当前已保存的 `data/derived/` 和 `public/v1/`。私有开发库不代表最新采集进度。
- **原神**：按版本和期数区分版本更新公告、祈愿预告、角色/武器祈愿公告、候选与正式 V1。暂未完成期数匹配的 7.2 等新公告，显示「待归期」，不能隐藏。
- **星铁**：一篇跃迁公告可能包含多个池，按「公告篇数 · 卡池数」展示；跨期持续开放的旧池按正式 V1 已核实的真实期数展示。星铁没有预告流程；版本更新公告目前不单独持久化，所以该列不会假称已解析。
- **缺失的含义**：`—` 表示本仓库未保存对应结构化记录，不等于官方未发布；缺角色/武器只提醒检查，不阻断抓取或发布。候选与 V1 的数字按卡池计。
- **时间和运行**：独立的 `4-1_卡池公告识别状态一览` Action 北京时间每日 16:17 定时运行，也可手动运行。仅生成、提交 Markdown，**不联网抓公告、不 OCR、不组装候选、不改变 V1**。
- **开发与测试**：私有仓库验证后提交到公开库，公开运营仓库不保存开发测试文件。

手动在已检出的仓库执行：`python -m scripts.release.generate_banner_status`。
