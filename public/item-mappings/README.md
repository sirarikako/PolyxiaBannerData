# 物品名称与 ID 对照表

本目录提供与 UIGF 字典相同的「**物品名称 → 物品 ID**」JSON 格式，按游戏和语言分开存放，用于查询玩家抽卡记录中的 `item_id`。原神与星铁的 ID 空间独立，不能跨游戏混用。

## 简体中文（`zh-CN`）

| 游戏 | 对照表 |
| --- | --- |
| 原神 | [genshin/zh-CN.json](./genshin/zh-CN.json) |
| 崩坏：星穹铁道 | [starrail/zh-CN.json](./starrail/zh-CN.json) |

示例（仅示意，实际条目以 JSON 文件为准）：

```json
{
  "温迪": 10000022,
  "风鹰剑": 11501
}
```

键为**简体中文物品名称**，值为**正整数物品 ID**。该格式与 UIGF 字典结构兼容，可根据名称查 ID，也可以由使用方自行建立反向索引。文件没有内嵌元数据，便于直接作为字典使用。

## 收录范围与注意事项

- 当前首版仅收录已发布卡池 v1 中明确带有简体名称与有效 `itemId` 的五星、四星物品，不应视为游戏完整物品库；尤其不能据此断言涵盖全部三星武器或常驻非 UP 物品。
- UIGF 官方提供原神与星铁的简体字典，路径为 `https://api.uigf.org/dict/{game}/chs.json`。后续可在其原始字典基础上合并本仓库已验证的 v1 映射，保留 UIGF 原有条目。
- 名称冲突时不能直接覆盖原条目，应核实物品 ID 后再发布；未知 ID 不编造 `0` 或占位值。
- 本表与 [卡池 v1 数据](../v1/README.md)相互独立，不改变卡池 ID、Manifest 或 v1 数据格式。
- 目前只发布 `zh-CN`；其他语言以后按同样规则添加各游戏的对应语言文件，不通过简体名称自动翻译。

当前文件是依据 v1 构建的**初始对照表**，尚未导入在线 UIGF 完整字典，因此不要将它误认为 UIGF 官方字典的完整镜像。
